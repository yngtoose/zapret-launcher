# Discord / YouTube Ускоритель

Простой лаунчер в одну кнопку для сборки
[Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube).
Рассчитан на людей, которые не разбираются в компьютерах.

## Что делает по нажатию «Включить»

1. Скачивает **последний релиз** zapret с GitHub (если ещё не скачан или вышла новая версия).
2. Распаковывает его в `C:\ProgramData\ZapretLauncher` — путь без кириллицы, как требует zapret.
3. Находит **самую новую ALT-стратегию** (`general (ALT12).bat` и т.д.) и запускает её.
4. Повторное нажатие («Выключить») — закрывает обход (`winws.exe`).

Программа сама запрашивает права администратора (их требует драйвер WinDivert).
Состояние кнопки автоматически синхронизируется с реальным состоянием обхода.

## Запуск из исходника

```powershell
py -3.12 zapret_launcher.py
```

Сторонних зависимостей нет — только стандартная библиотека Python (tkinter входит в комплект).
Работает на Python 3.8+.

## Сборка в один .exe

```powershell
.\build.bat
```

Результат: `dist\ZapretBooster.exe` — один файл, который можно отдавать пользователям.
Его можно переименовать во что угодно (например, `Ускоритель.exe`).

> **Антивирус.** Внутри zapret лежит WinDivert — антивирусы иногда помечают его как
> `RiskTool.WinDivert`. Это не вирус, а легитимный инструмент перехвата трафика
> (см. предупреждение в README оригинального репозитория). При необходимости добавьте
> папку `C:\ProgramData\ZapretLauncher` в исключения антивируса.

## Как это устроено внутри

| Шаг | Деталь |
|-----|--------|
| Поиск релиза | GitHub API `releases/latest`, берётся ассет `*.zip` |
| Кэш версии | `C:\ProgramData\ZapretLauncher\version.txt` — повторно не качает ту же версию |
| Офлайн | Если GitHub недоступен, запускается уже скачанная версия |
| Выбор ALT | Регэксп `general (ALT<N>).bat`, берётся максимальный `N` |
| Без лишних окон | Перед запуском bat выставляется `NO_UPDATE_CHECK=1`, чтобы не выскакивала проверка обновлений |
| Старт/стоп | Запуск bat через `cmd /c`; остановка — `taskkill /IM winws.exe` |
